# Проверка адаптивности LAUTE

Требуются Playwright, установленный Google Chrome и тестовый WebKit (`playwright install webkit`). Playwright — инструмент QA; добавлять его в production-зависимости не требуется. Если пакет установлен вне проекта, укажите `PLAYWRIGHT_MODULE_PATH`; расположение браузеров можно задать через стандартный `PLAYWRIGHT_BROWSERS_PATH`.

После `npm run build` запустите `npm run preview -- --host 127.0.0.1`, затем:

```text
node scripts/verify_responsive.cjs chrome
node scripts/verify_responsive.cjs webkit
node scripts/verify_interactions.cjs chrome
node scripts/verify_interactions.cjs webkit
```

Третий аргумент может задавать другой адрес предпросмотра. Отчёты и снимки сохраняются в игнорируемой папке `.temp/`.

Первая проверка охватывает 7 страниц × 3 языка × 13 размеров экрана (320–1920 px, включая горизонтальный телефон), в том числе переполнение и перекрытие первого текста шапкой. Вторая переключает языки и все 7 регионов через интерфейс, проверяет границы шапки до 2560 px, прокрутку мобильного меню, все 6 слайдов, направление свайпов, остановку автопрокрутки вне экрана, reduced motion и отсутствие постоянных изменений стилей шапки при прокрутке. Направление свайпа проверяется синтетическими событиями; мобильные профили iPhone 13 и Pixel 7 дополнительно проверяют касания, DPR и мобильный viewport. Проверка CMS ограничена ссылкой в футере и формой с одним полем пароля; попыток входа и записи данных нет.

WebKit на Windows и размеры viewport дают проверку движка и вёрстки. Они не заменяют проверку на физических MacBook, iPhone и Android, включая поведение системных панелей, клавиатуры и конкретного GPU.

Регрессия казахского меню проверяется отдельным условием: на широком desktop (от 1512 CSS px) должны отображаться все 7 пунктов, их центры должны принимать клики, а кнопка компактного меню должна быть скрыта. Холодные контексты RU/KZ/EN проверяют сохранённый язык, задержку шрифтов, повторную загрузку, переходы по каждому пункту и стабильность режима. Это условие независимо от формулы замера ширины: предыдущая проверка могла принять свёрнутое меню даже в окне 2539 px.

В Chrome дополнительно применяется настоящий page zoom 80%, 100%, 110%, 125%, 150%, 175% и 200% через Preferences одноразового тестового профиля. Тест проверяет изменение `devicePixelRatio` и CSS-ширины при неизменном pinch-scale. Профили создаются внутри `.temp/` и удаляются после закрытия браузера; личный профиль не используется. Ключи настроек соответствуют [реализации Chromium](https://chromium.googlesource.com/chromium/src/+/lkgr/chrome/browser/ui/zoom/chrome_zoom_level_prefs.cc).
