# LAUTE Project Rules & Instructions

## 1. Автоматическое обновление продакшн-сайта
- **Официальный живой адрес сайта**: `https://markpronenko7-cloud.github.io/laute/`
- **Правило**: При любых доработках, изменениях и обновлениях проекта **всегда синхронизировать и обновлять этот сайт** (коммит и push в ветку `main`, где GitHub Actions автоматически собирает и публикует проект на GitHub Pages).

## 2. Закрытая панель управления (CMS)
- Доступ осуществляется через незаметную ссылку **«Управление»** в самом низу футера (`/admin`).
- Авторизация работает **строго по одному полю «Пароль»**.
- Защита реализована на криптографическом `scrypt`-хешировании с защитой от перебора (rate limiting).
- Управление контентом, страницами и каталогом доступно сотрудникам без кода и без GitHub.

## 3. Критическое требование: AI LAUTE
- **Категорически запрещено** изменять, перестраивать, переобучать или модифицировать AI LAUTE (`src/ai/`).
- Всегда сохранять его изолированным и работоспособным.
